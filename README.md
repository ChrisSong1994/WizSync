# WizSync
WizSync 是一款基于 **Electron** 和 [**Unison**](https://github.com/bcpierce00/unison) 构建的专业级目录同步工具。它旨在为开发者和专业用户提供一个极其稳定、可视化且本地/跨磁盘的目录同步解决方案。

## ✨ 核心特性

- 🔄 **双向与单向同步**：基于成熟的 Unison 算法，支持双向同步（智能处理双向修改与冲突）；也可选择**单向镜像模式**（源 → 目标 / 目标 → 源），源端强覆盖目标端。
- ⚡ **高效同步**：默认开启快速检查（FastCheck），以大小 + 修改时间判定变更，仅对实际变更的文件做内容比对，避免全量哈希，大幅提升大数据量下的扫描速度。
- ⏱️ **灵活的同步模式**：
  - **定时检查**：按设定的分钟间隔自动执行。
  - **手动执行**：仅在点击同步按钮时运行。
  - 手动操作（如对比、忽略）完成后会自动触发增量同步；磁盘重连后自动恢复错误状态的定时任务。
- 📦 **开箱即用**：内置针对 macOS (Apple Silicon/Intel)、Windows (x64) 与 Linux (x64) 的 Unison 二进制文件，无需用户手动安装依赖。
- 📊 **可视化仪表盘**：
  - 实时查看同步状态与进度。
  - 详尽的统计信息（文件总数、目录大小）。
  - 图形化的文件差异对比 (Diff)。
- 💾 **备份与保留策略**：冲突/更新/删除前的文件自动备份到独立目录，支持设置保留天数与集中式管理（浏览、删除、定位备份文件）。
- 🚫 **忽略规则**：内置跳过隐藏文件与常见噪音（`node_modules`、`Thumbs.db` 等），并支持按路径自定义忽略。
- 📝 **深度日志系统**：
  - 按任务、按日期自动分割日志，读取时仅合并最近 7 天，防止日志文件过大。
  - 一键跳转日志文件夹。
- 🗂️ **Tray 菜单栏控制**：通过托盘图标快速监控正在运行的任务，无需打开主窗口。
- 🛡️ **冲突保护**：内置路径重复、父子嵌套及 symlink 解析后的重叠校验，防止因配置错误导致的同步回环或文件损坏。
- 🔌 **磁盘离线检测**：实时监控磁盘挂载状态，磁盘离线时自动挂起任务，重连后自动恢复同步。

## 📖 使用指南

1. **创建任务**：点击"新建任务"，选择源目录（Source）与目标目录（Target）。
2. **配置方向**：
   - **双向同步**：以最新修改为准，双向传播变更。
   - **源 → 目标 / 目标 → 源**（单向镜像）：源端强覆盖目标端，目标端多余文件会被自动删除（无二次确认，请谨慎设置）。
3. **选择模式**：
   - **定时检查**：设置间隔（分钟），系统按周期自动同步。
   - **手动执行**：仅在点击同步按钮时运行。
4. **查看差异**：同步前点击"对比"可预览两个目录间的文件差异，并可将选定路径加入忽略列表。
5. **管理备份**：在任务设置中开启备份，冲突与变更前的旧版本将保留在备份目录，可随时查看与恢复。
6. **管理日志**：点击任务卡片上的日志图标，查看详细的同步历史与错误排查信息。

## 🤝 贡献建议

我们非常欢迎 Issue 和 Pull Request！在提交代码前，请确保：
1. 代码注释保持中文化。
2. 遵循现有的模块化设计（如日志逻辑位于 `libs/logs.ts`，同步逻辑位于 `libs/sync-manager.ts`）。
3. 新增或修改核心逻辑时补充对应的 `vitest` 单测，并确保 `npm run build` 通过 TypeScript 类型检查。
